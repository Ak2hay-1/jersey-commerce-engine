# Home — Velocity match-day

Extends `design-system/jerzyfy/MASTER.md`.

## Stack

1. Glass pill header (Home · Shop · Customize)
2. Full-bleed floodlit hero (~90dvh) + floating tilted kit cards
3. Dual marquee (kit phrases)
4. Dark **COLLECTION** hover-scale grid
5. Light **TRENDING** masked type + 3D category coins
6. Light limited-edition carousel + oversized **JERZYFY** marquee
7. Dark trust + burgundy CTA close

## Hero

- Brand **Jerzyfy** hero-level
- One italic headline + one support line
- CTA: `.store-pill-accent` (burgundy)
- Floating product cards desktop-only; simplify on mobile
- Strong vignette / pitch-light gradient

## Light bands

- Use `.home-light-band` only — do not flip site theme
- Masked TRENDING via `background-clip: text` + Ken Burns stills
- Limited edition rounded media carousel with side arrows

## Success

First viewport reads floodlit match-day with Jerzyfy dominant; scroll reveals light Velocity mid-sections without washing out the rest of the shop.
