1. Platform overview

Jerzyfy runs on the Jersey Commerce Engine — a production-ready, multi-tenant commerce platform built for jersey and sportswear retail. Shop name, branding, catalog, and domain are tenant data, not hard-coded in the product.

One platform serves three sales channels: a premium customer website, an in-store POS register, and a full ERP/admin staff portal — all sharing one inventory, CRM, and payment ledger.

3. Multi-tenant platform & staff access

Tenant isolation

Every record is scoped to a tenant. JWT carries tenantId; the API never crosses shop boundaries.

Custom domains

Storefront resolves branding and catalog from the shop’s host / subdomain.

Staff authentication

Email/password login, refresh-token rotation, forced password change, Redis session denylist.

Realtime sync

WebSocket invalidate events keep POS and ERP views in sync after sales and stock changes.

Roles

Fine-grained permission codes (60+) cover products, inventory, sales, orders, custom orders, reports, and settings. User management lives under Users in the staff portal. Money and stock mutations are audit-logged.

8. Ecommerce orders (ERP)

Staff manage website (and channel) orders from a shared order model.

  • Sources: Website, POS-linked, WhatsApp, Manual
  • Status flow: Pending → Confirmed → Processing → Ready → Shipped → Completed (plus cancel / return / refund paths)
  • Pickup path: Store pickup skips the Shipped step
  • Stock: Reserve at checkout; release on cancel; consume on complete
  • Safety: Idempotent checkout with cart lock
  • Revenue: Completed orders counted once (not double-counted with linked POS sales)

Domain specialty for Jerzyfy: bulk and team kit workflows from enquiry through production — not a generic “contact form.”

Custom jersey, team, corporate, college, tournament, bulk.

Guest enquiry

Quotes

Versioned quotes (QT-###### v1/v2…); accept, supersede, or expire.

Ordering modes

Player list (name / number / size) or size-quantity matrix.

Customization pricing

Tenant-priced fixed, per-item, or percentage options — snapshotted on quote.

Design approval

Upload versions; request approval; approve or request changes via public token.

Deposits & balances

Payment state tracked separately from production status.

Production tracking

Design → materials → production → QC → ready; timeline and notes.

ERP filters: Enquiries / Quotes / Production. Dedicated custom-orders report available.

10. Payments & refunds

Payment methods

Cash, UPI, Card, Online, Bank transfer, Other — shared ledger for POS sales, ecommerce orders, and custom orders.

  • Duplicate UPI/card reference guard per tenant method
  • Razorpay settings UI with encrypted secrets (live online capture is later-phase)
  • Today’s online flow: COD, pay-in-store, or staff-recorded payment in ERP/POS

Refunds & receipts

  • Full or partial refunds with restock modes: Restock / Damage / None
  • Refund payment rows are append-only (originals never deleted)
  • Frozen HTML receipt payloads for reprint; thermal browser print for POS

13. Expenses

Operating expense tracking for shop P&L visibility (not a full accounting ledger).

  • Seeded categories: Rent, Electricity, Salary, Transport, Marketing, Packaging, Maintenance, Misc

  • Only active expenses count in totals and reports

14. Dashboard & reports

KPI dashboard

Revenue, COGS, gross profit/margin, orders, AOV, customers, inventory value, supplier outstanding, expenses — with date presets (today, yesterday, 7d, 30d, this/last month, custom) in the tenant timezone (default Asia/Kolkata).

Cards are role-filtered (e.g. cashiers see ops KPIs, not gross profit/expenses by default). Results are Redis-cached briefly per tenant/user.

17. Jersey & sportswear domain fit

Jerzyfy’s first live tenant is a jersey retail business. The product is shaped for that trade:

  • Product shape: Club kits, national kits, kids, custom/print bases; adult S–XXL and kids sizes as one variant per size
  • Imagery: Front / side / back product shots; collection tiles for homepage merchandising
  • Customization commerce: Names and numbers, team colours, player lists, bulk size matrices, design approval, deposits before production
  • Channels: Walk-in POS + website catalog + custom/team enquiries (WhatsApp/manual as order sources)
  • India retail ops: INR, UPI tender, Asia/Kolkata reporting, MSG91 OTP option
